# flutter-widgets-[прізвище]

Практична робота 5 «Розробка віджетів у Flutter» 
## Опис проєкту

Flutter-додаток із власними віджетами: `ProfileWidget`, `CustomButton`, `AnimatedCounter`, `ProductCard`. Стан застосунку — `AppState` (`ChangeNotifier`).



## Структура

```text
lib/
├── main.dart
├── screens/   home_screen, profile_screen, products_screen
├── widgets/   custom_button, product_card, profile_widget, animated_counter
├── models/    user, product
└── utils/     constants, themes, app_state
```

## Реалізовані віджети

| Віджет | Тип | Опис |
| --- | --- | --- |
| ProfileWidget | Stateless | 
| CustomButton | Stateless | 
| AnimatedCounter | Stateful |
| ProductCard | Stateful |
